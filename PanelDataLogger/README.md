# PanelDataLogger

**العربية** | [English](README.en.md)

إضافة Spigot/Paper صغيرة ومرافقة لـ **MC Panel**، بمهمتين:

## 1) خادم HTTP داخلي — بيانات اللاعبين المتصلين حيّاً

هذا هو الجزء **الأهم**. بدلاً من انتظار Minecraft يحفظ ملف اللاعب على
القرص (يحدث فقط عند `/save-all` أو مغادرة اللاعب)، أو محاولة تحليل رد أمر
كونسول نصي (بطيء وهش)، تشغّل هذه الإضافة خادم HTTP صغيراً على
`127.0.0.1` فقط، تقرأه اللوحة (`server.js`) مباشرة عبر طلب HTTP عادي:

```
GET http://127.0.0.1:28281/player/<name>
```

يرجع بيانات اللاعب (مخزون رئيسي، دروع، يد ثانية، صندوق سحري، موقع، صحة،
جوع، خبرة، نمط لعب، وإحصائيات كاملة عبر Player#getStatistic) **مباشرة من
كائنه في الذاكرة إن كان متصلاً الآن** — بلا أي تأخير أو تخمين. هذا نفس
الأسلوب الذي تعتمده إضافات معروفة لربط سيرفرات Minecraft بلوحات خارجية
(مثل MCRest وWEB-API). إن لم يكن اللاعب متصلاً، ترجع اللوحة تلقائياً
لقراءة آخر ملف محفوظ على القرص كخطة بديلة.

**هذا الجزء لا يحتاج تركيب أي شيء إضافي على جهة اللوحة** — فقط تأكد أن
`PANEL_HTTP_PORT` في ملف `.env` الخاص باللوحة يطابق `port` في
`config.yml` الخاص بهذه الإضافة (كلاهما `28281` افتراضياً).

## 2) تسجيل أماكن الموت والانتقال في الكونسول

يبقى هذا الجزء ضرورياً بشكل منفصل، لأن Minecraft لا يكتب إحداثيات في
رسائل الوفاة أو الانتقال إطلاقاً — لا في الكونسول ولا حتى عبر خادم HTTP
أعلاه (الذي يعرض الحالة **اللحظية** فقط، لا التاريخ). تستمع هذه الإضافة
لحدثي الوفاة والانتقال وتطبع سطراً بصيغة ثابتة تقرأها اللوحة وتحوّلها
لسجل دائم لكل لاعب:

```
[PanelData] DEATH|<player>|<world>|<x>|<y>|<z>|<cause>
[PanelData] TELEPORT|<player>|<cause>|<fromWorld>|<fx>|<fy>|<fz>|<toWorld>|<tx>|<ty>|<tz>
```

## بدون هذه الإضافة إطلاقاً

اللوحة تعمل، لكن:
- المخزون/الموقع/الصحة للاعب المتصل: يعتمد فقط على آخر ملف محفوظ (قد يتأخر)
- الإحصائيات الكاملة (وفيات، قتل، مسافات): تعمل دائماً بلا حاجة لهذه الإضافة، تُقرأ من ملف إحصائيات قياسي منفصل
- أماكن الموت والانتقال التاريخية: لن تظهر إطلاقاً

## البناء

يحتاج **JDK 25 فأعلى** (ماينكرافت 26.x يعمل على Java 25) وMaven.

```bash
cd PanelDataLogger
mvn package
```

الناتج: `target/PanelDataLogger.jar`

> الإضافة مبنية على `spigot-api 26.3-R0.1-SNAPSHOT`. إذا ظهر خطأ في تنزيل `spigot-api`: عدّل `<spigot.api.version>` في
> `pom.xml` لتطابق نسخة الـ jar التي بنيتها عبر BuildTools لتشغيل سيرفر
> 2b2t Arab نفسه (هي غالباً موجودة أصلاً في `~/.m2` المحلي عندك).

## التركيب

1. انسخ `PanelDataLogger.jar` إلى `/opt/minecraft/plugins/`
2. أعد تشغيل السيرفر
3. تأكد من ظهور هذين السطرين عند الإقلاع:
   ```
   خادم HTTP الداخلي يعمل على 127.0.0.1:28281 (لبيانات اللاعبين الحية للوحة).
   PanelDataLogger جاهزة — تسجيل الوفيات والانتقالات لصالح MC Panel مفعّل.
   ```
4. تحقق مباشرة من الجهاز نفسه (وليس من متصفحك) أن الخادم يستجيب:
   ```bash
   curl http://127.0.0.1:28281/health
   # المتوقع: {"status":"ok"}
   ```
   لو ظهر خطأ اتصال هنا، المشكلة في الإضافة نفسها (لم تُثبَّت، أو تعطّل
   المنفذ من إضافة أخرى) — راجع `plugins/PanelDataLogger/config.yml`
   لتغيير المنفذ عند الحاجة، مع تحديث `PANEL_HTTP_PORT` في `.env` باللوحة
   ليطابقه.

لا صلاحيات جديدة ولا أوامر جديدة داخل اللعبة — الإعداد الوحيد هو المنفذ.
